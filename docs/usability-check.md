# First-time usability check

Ask two people who have never seen Live Patch to start from the welcome screen and reach a shipped patch, Demo or real, without coaching. Use a fresh browser profile for each person. Start the timer on first page load and stop when the patch is visible in the Play window and OBS overlay. The target is under five minutes for each person.

| New participant 2 | Pending | Pending | Pending | Pending |

Record the browser and whether the person chose Demo or Codex. Note any help given; a coached run does not satisfy the criterion. Do not record account names or private Twitch messages here.
